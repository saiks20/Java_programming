# Java Notes

### Data Types in Java
1. Java has 2 types, primitive and reference types. 
2. Primitive types are stored as value, reference types saves the pointer. 
3. Datatypes examples are given datatypes package.

### Operators and Operations with Primitive Types
1. There are multiple types of operators in java,unary, binary operators, logical, bitwise, assignment etc.
2. BigDecimal class is used for doing rounding calculation on numbers.
3. Math class is used to do mathematical operations like sqrt, trigonometric etc.


### Java Control statements
1. Java has control statements like if, else, switch, for, while, do-while, break, continue, return etc.
2. if else is used to check the condition and execute the block of code accordingly.
3. Switch statement is used to execute one block of code from multiple options based on the value of a variable.
4. Switch statement can be used with byte, short, int, char, String and enum types. Can't be used with long, float, double, boolean types.
5. Switch statement can be used with multiple case labels, but only block is executed if break statement is used. 
6. If break is not used, then all the blocks after the matching case will be executed.
7. If continue is used in switch statement, then it will skip the current case and move to the next case.
8. do while loop is used to execute a block of code at least once, and then check the condition to continue or exit the loop.
9. while loop is used to execute a block of code as long as the condition is true.
10. for loop is used to execute a block of code for a specific number of times.
11. For loop has three parts, initialization, condition and increment/decrement. All three parts are optional.
12. for(;;;) is an infinite loop, as there is no condition to exit the loop.
13. for(;condition;) can be used to execute a block of code as long as the condition is true, without initialization and increment/decrement.
14. break statement can be used to exit the immediate loop or switch statement. It can also be used with labels to exit outer loops.
15. continue statement can be used to skip the current iteration of the loop and move to the next iteration. It can also be used with labels to skip outer loops.
16. for each loop is used to iterate over the elements of an array or a collection. It can be used with arrays, collections, and streams.
17. Nested loops are used to execute a block of code inside another loop. The inner loop is executed for each iteration of the outer loop.
